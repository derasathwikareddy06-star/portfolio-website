Instructions for Customizing Portfolio Assets:

1. PROFILE PHOTO:
   - Place your portrait/headshot image here and name it `profile.jpg` (or `profile.png`).
   - In `index.html` (around line 95), uncomment the `<img>` tag and point it to `assets/profile.jpg`:
     `<img src="assets/profile.jpg" alt="Sathwika Reddy" class="profile-img">`

2. RESUME PDF:
   - Place your official PDF resume file here named `Sathwika_Reddy_Resume.pdf`.
   - Update the Download button in `index.html` or `script.js` to link directly to `assets/Sathwika_Reddy_Resume.pdf`.

3. PROJECT SCREENSHOTS (Optional):
   - You can add screenshots of your Streamlit apps or web apps inside this folder and reference them in `index.html`.

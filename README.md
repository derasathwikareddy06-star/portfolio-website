## 🚀 How to Run Locally

### Option 1: Direct File Open
Simply double-click `index.html` or right-click and choose **Open with > Google Chrome** (or any modern web browser).

### Option 2: Python HTTP Server
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

### Option 3: VS Code Live Server
1. Open the project in VS Code.
2. Right click `index.html` and click **"Open with Live Server"**.

## 🌐 Deployment Instructions

### 1. GitHub Pages (Free & Instant)
This repository (`derasathwikareddy06-star/portfolio-website`) is ready for GitHub Pages:
1. Push the latest code to GitHub:
   ```bash
   git add .
   git commit -m "Update portfolio website"
   git push origin main
   ```
2. On GitHub, go to your repository: **Settings > Pages**.
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Set branch to `main` and folder to `/(root)`.
5. Click **Save**. Within 1–2 minutes, your website will be live at:
   `https://derasathwikareddy06-star.github.io/portfolio-website/`

### 2. Vercel Deployment (Alternative)
1. Visit [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **"Add New Project"** and select `portfolio-website`.
3. Keep default settings (Framework Preset: Other / Root Directory: `./`).
4. Click **Deploy**. Vercel will provide an instant HTTPS URL with automatic redeployments on every push.
